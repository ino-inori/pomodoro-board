# 🍅 ポモドーロ・タスクボード

今日やることを3つまでに絞り、ポモドーロ・テクニックで集中するためのシンプルなタスクボードです。
HTML ファイル1つだけで動き、インストールやビルドは不要です。

## 使い方

1. `index.html` をブラウザで開きます。
2. 今日やることを入力して「追加」を押します(最大3つ)。
3. 取り組むタスクをクリックして選び、「スタート」を押します。
4. 25分の集中が終わるとチャイムが鳴り、選んでいたタスクに 🍅 が1つ付きます。続けて5分の休憩に切り替わります。

## 機能

- 集中25分 / 休憩5分のタイマー(一時停止・リセット・スキップ)
- タスクごとのポモドーロ数と、合計の集計
- タスクの完了チェックと削除
- タスクとポモドーロ数はブラウザの `localStorage` に保存され、再読み込みしても残ります
- OS の設定に合わせたライト / ダークテーマ

## 補足

- データは開いているブラウザの中だけに保存されます。別のブラウザや端末とは共有されません。
- タイマーの残り時間は保存されないため、ページを再読み込みすると最初に戻ります。
